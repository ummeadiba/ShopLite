Run the app

git clone https://github.com/ummeadiba/ShopLite.git
cd ShopLite
node tools/static-server.js

Then open http://127.0.0.1:5173/login.html and sign in as qa@shoplite.test / Passw0rd!23.

The defects are the point. Every bug in app/ is planted on purpose — missing auth guards, XSS sinks, broken totals, logged passwords. Do not deploy this app anywhere public, and do not copy its patterns into anything real.
